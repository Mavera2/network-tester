**Ping Tester**, ağ bağlantılarını test etmek ve sorunları hızlıca teşhis etmek için geliştirilen modern ve kullanıcı dostu bir Windows Forms uygulamasıdır.  
Ping, traceroute, port tarama, packet loss gibi birçok ağ testi tek bir arayüzde sizler için birleştirmiş bulunmaktayım.

## 🚀 Özellikler

- 🔹 Ping Test – Gecikme süresi ölçümü  
- 🔹 Traceroute – Hedefe ulaşan yolun izlenmesi  
- 🔹 Open Port – Belirtilen IP’de açık port taraması  
- 🔹 Packet Loss – Paket kaybı analizi  
- 🔹 Whois – IP bilgileri sorgulama  
- 🔹 Speed, Bufferbloat, Jitter testleri (isteğe bağlı)  
- 🔹 Gelişmiş test ayarları (paket boyutu, frekans, süre vs.)  
- 🔹 Sonuçları dışa aktarma (.txt / .csv)
